## Export tips

- Keep the clean, light clinical palette intact — no browser chrome, crop to page content.
- PNG for UI screenshots. Aim for ~1600px wide and under ~600 KB each so GitHub loads fast.
- Use a 1280–1440px viewport at 2× device scale, then downscale, so retina stays crisp.
